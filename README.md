# Mantención QB

Panel público de equipos fuera de servicio (F/S) y operativos, alimentado con los reportes de los grupos de WhatsApp **Mecánicos QB** y **Supervisores TMF Rentamaq**.

- `index.html`: panel con 3 pestañas (Fuera de servicio, Equipos operativos, Dashboard KPI).
- `data.js`: datos de los equipos. Se actualiza diariamente a las 07:30 con los reportes de las últimas 12 horas.
